# 🛰️ HOLO-TABLE PRO — الكرة الأرضية الهولوغرافية الواقعية

مشروع خيال علمي (Sci-Fi HUD) للتحكم بكرة أرضية **واقعية بالكامل** باستخدام **حركة اليدين** عبر الكاميرا.

### ✨ الميزات الواقعية
- 🌍 **أرض حقيقية** بصور الأقمار الصناعية (Blue Marble) + **أضواء المدن ليلاً** + لمعان المحيطات.
- ☁️ طبقة **غيوم** متحركة + **غلاف جوي** متوهج + خلفية نجوم حقيقية.
- 🗺️ **حدود جميع الدول** (GeoJSON) + **أكثر من 1200 مدينة حقيقية** مع التعداد السكاني.
- 🇸🇦 **دعم عربي كامل**: أسماء المدن والدول بالعربية + بحث بالعربي والإنجليزي.
- ✋ تحكم باليد (قرص/مباعدة) + تحكم احتياطي بالفأرة.

- **Three.js** → الأرض الواقعية ثلاثية الأبعاد + الحدود + المدن.
- **MediaPipe Hands** → تتبع اليد + نقاط توهج على الأصابع.
- **HTML5 Video** → بث الكاميرا العلوية في الخلفية.

## 🚀 خطوات التشغيل في VS Code

⚠️ **مهم:** لا يعمل المشروع بفتح `index.html` مباشرة (بروتوكول `file://` يمنع الكاميرا و ES Modules).
يجب تشغيله عبر **خادم محلي**. اختر إحدى الطرق:

### الطريقة 1️⃣ — إضافة Live Server (الأسهل)
1. ثبّت إضافة **Live Server** في VS Code.
2. اضغط بزر الفأرة الأيمن على `index.html` → **Open with Live Server**.
3. سيفتح المتصفح على `http://127.0.0.1:5500/...`.

### الطريقة 2️⃣ — خادم بايثون (Python) 🐍
افتح الطرفية (Terminal) داخل مجلد `standalone` ثم:
```bash
# بايثون 3
python -m http.server 8000

# على بعض الأنظمة
python3 -m http.server 8000
```
ثم افتح المتصفح على:
```
http://localhost:8000
```

### الطريقة 3️⃣ — Node.js
```bash
npx serve .
# أو
npx http-server -p 8000
```

## 🖐️ طريقة الاستخدام (الإيماءات)
| الإيماءة | الوظيفة |
|---|---|
| ✊ **قرص (Pinch)** بيد واحدة ثم التحريك | تحريك/دوران الخريطة (Pan) |
| 🖐️🖐️ **مباعدة/تقريب اليدين** | تكبير وتصغير (Zoom) |
| 🔍 **كتابة اسم مدينة** في شريط البحث | طيران سلس للموقع (Fly-To) |
| 🖱️ **سحب الفأرة / العجلة** | تحكم احتياطي بدون كاميرا |

1. اضغط **ACTIVATE CAMERA** واسمح بإذن الكاميرا.
2. ضع الكاميرا في وضع علوي (Overhead) فوق يديك للأداء الأمثل.
3. ابحث عن مدينة (مثال: Baghdad, Tokyo, London) وشاهد حركة الطيران.

## 🔧 تخصيص
- **إضافة مدن:** أضف عناصر إلى مصفوفة `CITIES` في `script.js`.
- **الألوان النيون:** غيّر متغير `--neon` في `index.html`.
- **حساسية الإيماءات:** عدّل معاملات `rotateBy(... * 3.2)` و `zoomBy(1 - dl * 5)`.

> 🗺️ لدمج **Mapbox GL JS** بدل الكرة الأرضية: استبدل قسم Three.js بخريطة Mapbox واستدعِ
> `map.flyTo({ center: [lon, lat], zoom: 10 })` داخل دالة `flyTo`.
