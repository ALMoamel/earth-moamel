# 🌍 HOLO-TABLE PRO — نسخة أوفلاين (تعمل بدون إنترنت)

هذه النسخة تحتوي **كل الملفات محلياً** (Three.js، MediaPipe، صور الأرض، بيانات
الدول والمدن، الخطوط) — تعمل **بدون أي اتصال بالإنترنت** بعد التحميل.

---

## 📁 محتويات المجلد
```
offline/
├── index.html          ← الصفحة الرئيسية
├── script.js           ← منطق الأرض + تتبع اليد + البحث
├── ar-data.js          ← الترجمة العربية
├── fonts/              ← الخطوط (Orbitron, Rajdhani, Cairo)
├── vendor/
│   ├── three.module.js         ← محرك ثري دي
│   └── mediapipe/              ← تتبع اليد (hands + wasm + نماذج)
├── img/                ← صور الأرض (نهار/ليل/ماء/نجوم/غيوم)
└── data/               ← حدود الدول + 1250 مدينة (GeoJSON)
```
> ⚠️ لا تحذف أو تنقل أي مجلد — كلها مطلوبة للعمل أوفلاين.

---

## ▶️ طريقة التشغيل (مهم جداً)

⚠️ **لا يعمل** بالضغط المزدوج على `index.html` مباشرة (بروتوكول `file://`
يمنع ES Modules وتحميل الملفات). **يجب** تشغيله عبر **خادم محلي** — لكن
الخادم المحلي **لا يحتاج إنترنت**، فقط يقدّم الملفات من جهازك.

### 🐍 الطريقة 1 — خادم بايثون (الأفضل للأوفلاين)
افتح الطرفية (Terminal) داخل مجلد `offline` ثم:
```bash
python -m http.server 8000
```
> أو `python3 -m http.server 8000`

ثم افتح المتصفح على:
```
http://localhost:8000
```

### ⚡ الطريقة 2 — Live Server في VS Code
1. ثبّت إضافة **Live Server** (مرة واحدة فقط — تحتاج إنترنت للتثبيت).
2. بعدها تعمل أوفلاين: يمين على `index.html` → **Open with Live Server**.

### 🟢 الطريقة 3 — Node.js
```bash
npx serve .
```

## 🖐️ الاستخدام
| الإيماءة | الوظيفة |
|---|---|
| ✊ قرص بيد واحدة + تحريك | تحريك/دوران الأرض |
| ✊✊ قرص باليدين + مباعدة/تقريب | تكبير / تصغير |
| 🔍 كتابة اسم مدينة | طيران للموقع |
| 🖱️ سحب الفأرة + العجلة | تحكم احتياطي |

1. اضغط **ACTIVATE CAMERA** واسمح بإذن الكاميرا.
2. اختر الكاميرا من القائمة (تدعم الكاميرا الخارجية).
3. ابحث عن أي مدينة (عربي/إنجليزي) للطيران إليها.

## 💾 الحجم الإجمالي
حوالي **35 ميجابايت** (أكبرها ملفات MediaPipe للذكاء الاصطناعي وصور الأرض).

## ❓ حل المشكلات
- **شاشة بيضاء:** تأكد أنك تفتح عبر `http://localhost` وليس `file://`.
- **الكاميرا لا تعمل:** امنح الإذن، أو استخدم تحكم الفأرة (زر SKIP).
- **بطء أول مرة:** ملفات MediaPipe كبيرة؛ تُحمّل من القرص بسرعة بعدها.
