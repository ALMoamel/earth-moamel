# 🌍 HOLO-EARTH — أرض واقعية مثل Google Earth

نسخة متقدمة تعرض **كل شيء** مثل Google Earth: صور أقمار صناعية عالية الدقة تتوضّح
كلما كبّرت حتى مستوى الشارع، أسماء كل الدول والمدن والشوارع، تضاريس ثلاثية الأبعاد،
ووضع الكرة الأرضية — مع تحكم باليد ودعم عربي كامل.

## ✨ الميزات
- 🛰️ **صور أقمار صناعية (ESRI World Imagery)** — تفاصيل تصل لمستوى الشارع.
- 🏷️ **أسماء الدول والمدن والشوارع والحدود** (طبقة ESRI).
- ⛰️ **تضاريس ثلاثية الأبعاد (3D Terrain)** من بيانات ارتفاع حقيقية.
- 🌐 **وضع الكرة الأرضية (Globe)** + غلاف جوي.
- 🔍 بحث عالمي بالطيران (FlyTo) — عربي وإنجليزي.
- ✋ تحكم باليد (قرص للتحريك، مباعدة اليدين للتكبير) + الفأرة.

## 📁 الملفات
```
earth/
├── index.html   ← الواجهة + الخريطة + HUD
├── earth.js     ← MapLibre + تتبع اليد + البحث
├── ar-data.js   ← الترجمة العربية
└── README.md
```
> كل شيء عبر CDN مجاني بدون أي مفتاح API. يتطلب **اتصال إنترنت**.

## ▶️ التشغيل في VS Code
افتح الطرفية داخل مجلد `earth` ثم:
```bash
python -m http.server 8000
```
وافتح: **http://localhost:8000**

أو استخدم إضافة **Live Server** (يمين على index.html → Open with Live Server).

## 🖐️ الاستخدام
| الإيماءة | الوظيفة |
|---|---|
| ✊ قرص (Pinch) + تحريك | تحريك الخريطة |
| 🖐️🖐️ مباعدة/تقريب اليدين | تكبير / تصغير |
| 🔍 كتابة اسم مدينة | طيران للموقع |
| 🖱️ الفأرة | سحب + عجلة + زر يمين للإمالة/الدوران |

الأزرار أسفل اليسار: تبديل الأسماء / التضاريس 3D / الكرة / إعادة الضبط.
